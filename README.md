#  Water Usage Tracker App

A beginner-friendly Android application designed to help users track their daily water consumption in various household activities such as drinking, bathing, washing, and cleaning. This mini project promotes sustainable habits and helps users understand their water usage better. The app uses **Firebase** for both authentication and real-time data storage.

---

##  Features

- **"Login and Register using Firebase"**  
  Secure authentication system using Firebase to manage users.

- **"Water Usage Entry Page"**  
  Users can input litres used for Drinking, Bathing, Washing, and Cleaning.

- **"Total Water Usage Calculation"**  
  Automatically calculates the total litres used and stores it in the Firebase Realtime Database.

- **"Realtime Data Saving"**  
  Each entry is saved under the user's unique ID in Firebase for future reference.

- **"Usage History Page"**  
  Users can view their previously recorded water usage entries.

- **"Clear Fields on Save"**  
  After submitting, all fields are cleared to ensure easy re-entry for the next day.
